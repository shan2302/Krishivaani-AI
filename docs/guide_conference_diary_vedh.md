# Project Overview

KrishiVaani-AI is a multilingual, voice-enabled agricultural
question-answering system based on Retrieval-Augmented Generation (RAG).

The project focuses on providing grounded agricultural information through
a system supporting English, Hindi, and Kannada.

The project includes research, multilingual processing, agricultural
knowledge retrieval, voice input, and evaluation of LLM-only and
RAG-based approaches.
